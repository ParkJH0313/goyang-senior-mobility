# Overrides 이전 결과

작성일: 2026-10-17. 이번 범위는 기존 대화·전처리 기록·코드 상수·processed·Step 2~4의 물리 보정과 056 입력의 이전이다. v7 분석, 원자료 재전처리, 새 현장 검증은 수행하지 않았다. 기존 제출용 자료는 변경하지 않았다.

## 공간 보정 검증

**278개: Point 75개, LineString 203개.** 원본 사용 레이어의 좌표계는 모두 EPSG:5179다. 원래 좌표·중간 꼭짓점·순서를 그대로 저장하고 연결 참조를 실제 첫/마지막 꼭짓점에 맞췄다.

- 원본 구간 스냅샷 283개, GTFS 정류장 89개, OSM 노드 7개를 필요한 대상만 보존했다.
- 네트워크 결합 79개 중 4개는 같은 위치의 Point 결합, 75개는 양의 길이 연결선이다. 0길이 LineString을 만들지 않았다.
- CSV에서 복원한 278개 도형의 WKB 지문이 일치했다. 414개 끝점의 대상 대응과 선상 위치를 1mm 허용오차로 검사했다.
- 사용자 경위도·기존 API 경위도의 EPSG:5179 변환값은 저장 좌표와 1mm 이내 일치했다.
- 원본 ID·공통 필드·허용 action·지문·도형 참조·중복 연산을 검사했다. 같은 대상·필드의 복수 충돌 연산은 없었다.
- 과거 거리 기반 walk_time_s를 보정값으로 옮기지 않았다. 운정 내부 180초는 거리 비용과 구분했다.

이는 저장 형식과 기존 보정의 대응 검증이다. 새 원자료에 실제 적용할 때의 높이·통행권한·대상 변경 검사는 후속 v7 적용기에서 수행해야 한다.

## 056 입력

네 CSV는 기존 확정 입력과 바이트가 동일하다. 정류장 32행, 지선 3행, 공통구간 63행, 평일 출발표 80행(32·24·24)을 확인했다. 멱절 19:41편을 포함하고 중복 기점 출발은 없다. 과거 선정 격자 두 CSV와 파생 branch_parameters는 옮기지 않았다. BusMaps 원자료 연도 불명, 2025년 2·4월 시간표 결합, 중간 시각 추정의 한계를 유지했다.

## v7로 대체한 과거 판단

대곡역 추가통로 취소, 원릉 A측 접근안 폐기, 과거 가좌동·송포동 및 세 대표군집 고정 선정, 예전 보행속도·총보행 상한·분위/인접 방식·점수/캐시는 설명 기록에만 남겼다. v7 점수·군집을 새로 산출해야 한다.

이전 철도 환승의 `max(240, min_transfer_time - 60)` 보행 환산식은 v7과 충돌한다. 승인된 180/240/근거 있을 때 120초와 추가 탑승 60초를 보존하되 실제 보행과 GTFS 최소 경과시간을 분리하도록 인계했다. 최신 기준이 명확해 같은 항목의 재승인을 요청하지 않는다.

## 근거와 후속 범위

- 사용자 원본 첨부 7개를 근거 사본으로 보존했다. 송추 좌표 원본 Pictures 스크린샷 파일은 이전 시점에 없었지만, 대화의 수치와 기존 적용 점은 보존했다. 좌표를 다시 요청할 필요는 없다.
- 의료기관 35개의 전체 정밀도 좌표·원주소·매칭 주소·조회 방식은 보존했다. raw API 응답 40개는 이번 작업에서 읽거나 이전하지 않았다. 전체 응답 보존은 별도 데이터 인계에서 확인해야 한다. 기존 좌표 재사용은 가능하지만 응답 원문 전체 감사를 완료한 것은 아니다.
- 이전 기록에서만 사용자 확정으로 표시된 건물·OSM 판정과 직접 대화 판단을 구분했다. 모형 가정을 현장 확인으로 변경하지 않았다.
- 새 프로젝트 data의 전체 이전 검증, data/manifest, 전처리 코드의 overrides 적용, run.py와 분석 구현은 이번 완료 범위에 포함하지 않는다. 다른 작업의 파일은 변경하지 않았다.
- source_manifest.csv는 과거 입력·코드의 파일 지문이고, package_files.csv는 이 패키지 파일 지문이다. 필요한 보정값·근거는 프로젝트 안에 있으며 이전 제출용 경로를 실행 중 열지 않는다.

이번 이전에서 새 사용자 결정이 필요한 항목은 없다. 실제 v7 입력과 충돌하는 항목이 발생하면 해당 건의 영향만 검토한다. 이 보고서와 검증 코드는 이전 범위의 확인 기록이며 새 접근성 분석 결과가 아니다.
