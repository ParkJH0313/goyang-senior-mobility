# 056번 도촌·서촌·멱절 보완 입력

일부 지선 구간은 BIS에 등록되어 있지 않아 **BusMaps의 정류장 좌표와 경로로 보완**했다. 사용자가 위치안을 확인하고 분석 채택을 지시했다. 보완은 기존 056번의 자료 누락을 메우는 것이며 신규 교통서비스 제안이 아니다.

| 입력 | 내용 |
|---|---|
| stops.csv | 방향별 지선 정류장 32개, 좌표 EPSG:4326, 순서와 출처 |
| route_sources.csv | 지선 3개 왕복 polyline, precision 5, 출처·수집일·페이지 해시 |
| common_section.csv | 공통구간 63정차의 기존 ID·순서·승하차 조건·상대 도착/출발시간 |
| weekday_departures.csv | 평일 기점 출발표 80편: 도촌 32·서촌 24·멱절 24 |

네 파일은 기존 확정 입력을 바이트 단위로 복사했다. 과거 선정 격자 CSV와 파생 branch_parameters는 입력에서 제외했다. 기점은 각각 도촌·서촌·멱절 마을측 출발점이며 호텔 출발표로 해석하지 않는다.

## 기준 시점과 정확도

도촌은 2025년 2월, 서촌·멱절은 2025년 4월 15일 평일 표다. 멱절 19:41편을 포함한 최종 24편을 유지한다. 사용자 첫 캡처의 23행만 다시 전사하지 않는다. BusMaps 경로·좌표의 원자료 연도는 불명이며 수집일은 2026-10-16이다. 2025년 자료를 결합한 보완모형으로 명시하고 특정 2025년 3월 날짜의 실측 운행으로 표현하지 않는다. 출처 URL은 각 CSV에 있다. 이번 이전에서 웹 재확인은 하지 않았다.

## 재생성 계약

1. 대상 노선의 원본 route_id `BR_3100_241299005`와 기존 보완 식별자를 검사한다. 기존 5편과 보완 80편을 함께 남기지 않는다. 이미 동일 해시 보완이 있는 processed에는 중복 추가하지 않는다.
2. 방향별 지선 순서/BusMaps 선형과 공통구간 기존 ID를 결합한다. 하나의 운행편 안에서 지선→공통 왕복→지선 복귀로 이어지며 편이 끝난 뒤 다음 편에 무조건 계속 타는 연결은 만들지 않는다.
3. 공통구간 시각은 원자료 5편의 상대시간 중앙값을 저장한 common_section을 쓴다. 지선 구간은 선형 거리와 공통구간 유효속도 약 20.78441494467478km/h로 환산한다. 공통구간 소요는 76.117분이다. 정확한 속도는 같은 입력으로 재계산할 파생값이며 별도 설정 override가 아니다.
4. 직접 시간 근거는 기점 출발시각이다. 지선 중간정차·복귀 시각은 추정이므로 timepoint=0, 기점은 timepoint=1로 구분한다. 배차간격이나 운행기간을 구간 주행시간으로 간주하지 않는다.
5. 실제 교통법규·도로 선형을 측량한 경로가 아니며, 호텔 앵커와 원본 공통정류장 좌표 차이를 기존 ID를 유지한 근사로 연결한다. 접속시간을 0으로 생략하는 별도 환승을 만들지 않는다.
6. 일반 재현은 이 네 입력을 이용하며 네트워크 접속/웹 조회가 필요 없다. GTFS 보완 구현은 앞으로 preprocess/07_gtfs_supplements.py로 이관한다. 이번 패키지는 알고리즘 이관 완료를 의미하지 않는다.
